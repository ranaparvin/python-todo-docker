# Python Todo App

A simple Todo web application built using Flask and Docker.

## Features

- Add tasks
- Delete tasks
- Simple user interface
- Docker support
- Docker Compose support

## Technologies Used

- Python
- Flask
- Docker
- Docker Compose
- Git
- GitHub

## Project Structure

```
python-todo-app/
│── app.py
│── Dockerfile
│── docker-compose.yml
│── requirements.txt
│── README.md
```

## How to Run

### Clone the repository

```bash
git clone https://github.com/ranaparvin/python-todo-docker.git
```

### Go to the project folder

```bash
cd python-todo-docker
```

### Build and run Docker

```bash
docker compose up --build
```

### Open in Browser

```
http://localhost:5000
```
